# Модуль «Управління завданнями» (Task Manager)

Веде реєстр завдань у Google Sheets: створення, оновлення статусу,
пошук відкритих та прострочених завдань.

## Структура таблиці

Аркуш `Завдання`, перший рядок — заголовки:

| ID | Завдання | Відповідальний | Термін | Статус | Примітки |
|----|----------|----------------|--------|--------|----------|

- **Термін** — у форматі `YYYY-MM-DD` або `DD.MM.YYYY`.
- **Статус** — `Нове`, `В роботі`, `Виконано`, `Скасовано`.

## Використання

```python
from modules.task_manager.tasks import TaskManager

tm = TaskManager("SPREADSHEET_ID")

tm.get_open_tasks()          # відкриті (незавершені) завдання
tm.get_overdue_tasks()       # прострочені завдання
tm.add_task("Замовити ШВЛ-контури", assignee="Іваненко", deadline="2026-09-25")
tm.update_task_status("a1b2c3d4", "Виконано")
```

## Методи

| Метод | Опис |
|-------|------|
| `get_open_tasks()` | Повертає всі незавершені завдання. |
| `get_overdue_tasks()` | Повертає завдання, термін яких минув. |
| `add_task(...)` | Додає нове завдання (генерує ID). |
| `update_task_status(task_id, status)` | Оновлює статус за ID. |
