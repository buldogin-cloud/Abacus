# Модуль «Управління завданнями» (Task Manager)

Веде реєстр завдань у Google Sheets: пошук відкритих та прострочених
завдань, оновлення статусу.

## Структура таблиці

Таблиця «Секретар — реєстр завдань», аркуш `Реєстр`, перший рядок —
заголовки (10 колонок, A:J):

| Колонка | Назва | Опис |
|---------|-------|------|
| A | Пріоритет | 🔴 Критичний / 🔴 Терміново / 🟠 Високий / 🟡 Контроль |
| B | № документа | Номер наказу/листа (напр. `№286`) |
| C | Дата | Дата документа |
| D | Назва | Коротка назва завдання |
| E | Завдання / очікуваний результат | Детальний опис |
| F | Моя роль | Контроль / Виконання / Член комісії тощо |
| G | Виконавець / підрозділ | Відповідальні особи/підрозділи |
| H | Строк | Дата (`DD.MM.YYYY`) або опис (`Щодня`, `У процесі`) |
| I | Статус | Описовий текст стану |
| J | Остання відповідь / доказ | Підтвердження виконання |

### Логіка визначення стану

Статуси в реєстрі — **описові** (не фіксований набір), тому:

- **Завершене** — статус містить `виконано`, `закрито`, `скасовано` або
  `завершено` (але `частково виконано` вважається відкритим).
- **Прострочене** — статус містить `прострочено`, **або** з поля «Строк»
  вдалося витягти дату, і вона вже минула (і завдання не завершене).

## Використання

```python
from modules.task_manager.tasks import TaskManager

tm = TaskManager("SPREADSHEET_ID")          # аркуш «Реєстр» за замовчуванням

tm.get_open_tasks()          # відкриті (незавершені) завдання
tm.get_overdue_tasks()       # прострочені завдання
tm.get_all_tasks()           # усі завдання реєстру
tm.update_task_status(5, "Виконано")        # оновити статус у рядку 5 (колонка I)
```

Кожне завдання повертається як словник із нормалізованими ключами:
`Завдання`, `Деталі`, `Термін`, `Відповідальний`, `Статус`,
`Пріоритет`, `Документ`, `Доказ`, `_row` (номер рядка в таблиці).

## Методи

| Метод | Опис |
|-------|------|
| `get_open_tasks()` | Повертає всі незавершені завдання (нормалізовані). |
| `get_overdue_tasks()` | Повертає прострочені завдання. |
| `get_all_tasks()` | Повертає всі завдання реєстру. |
| `update_task_status(row, status)` | Оновлює статус (колонка I) за номером рядка. |
