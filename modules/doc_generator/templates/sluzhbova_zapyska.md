# ШАБЛОН: Службова записка

## Структура (еталон із ваших документів)

```
СЛУЖБОВА ЗАПИСКА

{addressee_position}          ← кому (посада, кілька рядків)
{addressee_org}              ← установа
{addressee_name}             ← ПІБ у давальному відмінку

Повідомляю Вам про {problem_statement}.
{context_and_facts}          ← факти, цифри, штатні дані, нормативні посилання

Прошу {request}.             ← прохання / пропозиція

З повагою,
{author_position}            ← посада автора
{author_name}                ← ПІБ автора
```

## Стильові правила (витягнуті з ваших записок)
- Офіційно-діловий стиль, звертання на «Ви» з великої літери.
- Починається з «Повідомляю Вам про...» або «Доводжу до Вашого відома...».
- Завершується «Прошу розглянути можливість...» / «Прошу вжити заходів...».
- Підпис: «З повагою,» → посада → ініціали і прізвище (А.В. Белінський).
- Конкретика: точні цифри ставок, назви підрозділів, нормативні акти (НСЗУ, накази МОЗ).
